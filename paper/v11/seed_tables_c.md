## C4. Model-family ceiling and protocol attribution

`anchor_fit_experiment.py`: all parameters trainable, full-pool pmf, 10^5 steps, one config per kernel/K setting, scored on anchor t = 1. The ceiling is the best config of the sweep.

**This sweep carries no seed.** Run at seeds 0, 1, 2, 3, 4 it returns bit-identical `corr` for every config, because nothing in the optimisation consumes the RNG: the pmf is the anchor's full native code pool (no subsample draw), the initialisation is data-dependent (`train_iqp.data_init_theta`), and the `auto3` bandwidths are resolved from that same pool. The seed does reach the run, and does move `pdf_js`, which is scored on a sampled field. So the model-family ceiling is a deterministic quantity and the `0.88-0.89` the paper cites is a range across configs, not a seed spread.

`sigma0.15` and `flat` are the same experiment: at sigma = 0.15 the Walsh weights collapse to the uniform `flat` weights to ten digits, so the two rows agree bit for bit by construction rather than by coincidence.

Two rows are given for the freeze because the first is a confounded contrast: `allparams_subsample5e4` is (freeze = off, subsample = on) while `paper_stage1` is (freeze = on, subsample = off), so both factors move at once. Holding subsample = on in both cells isolates the freeze.

**This block is where 5 seeds change the story.** At seed 0 alone the freeze read -0.078 and the pmf subsample read -0.038, which is the -0.08 / -0.04 split Appendix B cites. Over 5 seeds the freeze is -0.1135 ± 0.0209 and the subsample is -0.0010 ± 0.0222, i.e. the subsample term is indistinguishable from zero and the freeze is correspondingly larger. The seed-0 split was an artefact of `paper_stage1` landing high at that seed (0.8074 against a 5-seed mean of 0.7646 ± 0.0261): that cell freezes theta_lat at a random N(0, 0.01) draw, so it is the most seed-sensitive cell in the table. The confounded and unconfounded freeze contrasts now agree (-0.1135 ± 0.0209 vs -0.1145 ± 0.0024) precisely because the factor separating them is null. The honest 5-seed statement is that stage 1 freezing theta_lat is essentially the whole protocol penalty, and the 5x10^4-sample pmf costs nothing measurable.

The factors are still not fully crossed (there is no all-parameters + full-pool cell at 3x10^4 steps), so these remain approximate attributions rather than a variance decomposition, the same caveat the earlier write-up carries.

## C5. Metric-calibration references

The Conv2D encoder seed is fixed at `evaluate.py`'s `CONV_SEED = 0` for every row, so these live in the same feature space as every arm above; only the shuffle draw varies.

`linear_interp_of_bracketing_anchors` here is **not** the same object as C1's CTRL-interp arm, and the two are expected to disagree. This row interpolates the raw anchor fields, reproducing the 0.9998 correlation the paper cites (source: `diag_scripts/q4_task_triviality.py`). The CTRL-interp arm interpolates the *quantised* anchor fields, because every generative arm is capped at 6-bit z and the zero-parameter control is held to the same cap (`controls.run_interp`). That is why CTRL-interp scores PDF-JS 0.00119 in C1 while this row scores 0.00010: the quantisation is a deliberate handicap, not a discrepancy.
